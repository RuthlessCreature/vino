# 近期验收路径

## 端到端主链路

1. 启动 `vino_cloud` 或 `vino_platform`。
2. iPhone 登录 Cloud。
3. Cloud 按用户分配一个 CoreML 模型。
4. iPhone 拉取模型目录，只能看到已授权模型。
5. iPhone 申请下载票据并下载加密包。
6. iPhone 解密、校验 hash、安装模型。
7. iPhone 启用模型，打开实时推理。
8. 拍照或视频流生成推理结果。
9. iPhone 上传图片和推理结果到 Cloud ingest。
10. Cloud 后台能看到资产、结果、下载、租约和审计记录。

## 必过负向场景

- 未登录请求模型列表返回 `401`。
- 无授权账号模型列表为空。
- 无授权申请下载票据返回 `403`。
- 下载票据过期后下载返回 `404` 或 `403`。
- 设备绑定不匹配不能下载或续租。
- 模型 hash 不匹配时 iPhone 安装失败。
- 重复 ingest `idempotencyKey` 不重复落库。
- 普通用户不能访问运营、审核、财务接口。

## 本地验证命令

```sh
cd vino_cloud
npm start
```

```sh
cd vino_platform
npm start
```

```sh
cd vino_iPhone
xcodebuild -project vino_iPhone.xcodeproj -scheme vino_iPhone -sdk iphonesimulator -configuration Debug build CODE_SIGNING_ALLOWED=NO
```
